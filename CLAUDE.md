## Architecture map

- `scripts/*.py`: CLI entry points. Collectors (`collect_pr_records.py`, `collect_source_inventory.py`, `list_merged_prs.py`), builders (`build_trajectory_jsonl.py`, `build_manifest.py`, `build_status.py`, `build_eligibility_ledger.py`), validators and CI contract checks, and exporters (`export_hf_dataset.py`, `export_observable_actions.py`).
- `scripts/lib/`: shared code. `github_client.py` (read-only API client), `collect_events.py`, `normalize*.py` (v0 and v1 normalizers), `migrate_v0_*.py`, `eligibility*.py`, `corpus_shard*.py`, `hermes_*.py`, `model_admission*.py`, `ci_*.py`.
- `schemas/`: JSON Schemas (`pr_trajectory` v0, `trajectory_v1`, `trajectory_v1_1`, eligibility, corpus shard, Hermes, model admission).
- `datasets/`: `jsonl/` (curated records), `cards/`, `manifests/` (source of `STATUS.md`), `inventory/v0.7/`, `hf/` (export). `raw/` and `artifacts/` hold untracked output.
- `docs/`: `data-policy.md`, `ci-contracts.md`, `event-collector.md`, and per-repo notes in `docs/source-repos/`. `providers/` and `evals/` are placeholders (`providers/README.md` only).
- `tests/`: pytest suite with fixtures in `tests/fixtures/`. `.github/workflows/ci.yml` defines the CI jobs, including `shared-files-guard`.

## Invariants and non-goals

- Collection is read-only. Collectors perform no GitHub writes, and nothing here may add write automation.
- Do not run collectors against live GitHub orgs, and never use or export a `GITHUB_TOKEN`, from an agent session. Work from committed fixtures and datasets.
- Preserve provenance: every record keeps its source repo, PR, and originating license; source-derived data is not relicensed (`NOTICE`, `docs/data-policy.md`).
- Raw dumps stay out of git (`datasets/raw/`, or `$PROMETHEUS_DATA_ROOT`). No secrets, private URIs, local paths, model weights, or raw closed-model chat logs in committed data.
- Do not weaken a schema, policy, or CI gate to make a record pass. Fail closed, as local-model admission does.
- `STATUS.md` and `docs/source-repos/_index.md` are generated by `scripts/build_status.py`; do not hand-edit them in a data PR.
- Python source files carry no SPDX headers; do not add them.

## Gotchas

- Runtime dependency is only `jsonschema[format]` (`requirements.txt`). There is no `pyproject.toml`, so there is no packaging or publish list to update.
- `.claude/` is not gitignored; do not commit local agent state there. `.kilo/` and `.beads/*` are ignored.
- `pytest` exits 5 when no tests are found and CI treats that as a pass, so a mis-pointed run can look green. Check the pass count.
- Never run publish or upload commands (Hugging Face export is a separate, human-run step).
- Edit only what the task needs.
